# Contributing Guidelines

## How to Contribute
We welcome contributions in the following areas:
- Bug fixes and performance improvements
- New detection logic and heuristic patterns
- Additional reputation source integrations
- Documentation and SOC playbook improvements

## Secure Contributions
- **Do NOT** submit live malware or malicious binaries in pull requests.
- Email samples provided for testing **must be sanitized** of PII and real credentials.
- Ensure no personal API keys or sensitive configurations are committed.

## Code Style
- Use clear, descriptive function and variable names.
- Prioritize security-first logic and defensive programming.
- Comment detection assumptions clearly to aid forensic audits.
